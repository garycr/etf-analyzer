# Customer Documents — Privacy & Handling Guidance

> **⚠️ This folder may contain sensitive customer data.**

## What belongs here

- Legacy code samples for analysis
- Project objectives and requirements
- Research documents and competitor analysis
- Meeting transcripts (anonymized where possible)
- UX designs and wireframes
- Architecture documentation

## What does NOT belong here

- Personally identifiable information (PII)
- Financial records, salary data, or HR documents
- Legal memos or attorney-client privileged materials
- API keys, passwords, or credentials
- Classified or export-controlled data

## Retention Policy

- **Delete imported files after Ring 0 intake is complete.** These files are inputs, not deliverables.
- Deliverables produced from these inputs belong in `docs/artifacts/`.
- Consider adding `docs/customer-docs/` to `.gitignore` if working with sensitive materials.

## Cloud Sync Warning

If this workspace is on OneDrive, SharePoint, or another cloud-synced drive, files in this folder will be synchronized to the cloud. Ensure all imported files are appropriate for cloud storage.
